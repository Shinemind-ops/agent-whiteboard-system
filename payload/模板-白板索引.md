# 白板索引

每個 session 恰有一塊白板，檔名＝session id。**最多一塊，禁止零塊。**

**骨架 11 欄固定**（①專案規則→⑪怎麼找回），定義與逐欄規格見 skill `whiteboard-system`。
舊制「現行／歸檔」兩區制、日期流水節已廢——白板不是日誌。

白板住 `<白板根>\<session_id>.md`；已結束的移到 `歸檔\`。

| session_id | 目標／主題 | 建立 | 最後活躍 | 完整路徑 |
|---|---|---|---|---|
| （範例）20260101_120000_abcdef | 這塊板在做什麼 | 2026-01-01 | 2026-01-01 | `<白板根>\20260101_120000_abcdef.md` |

## 怎麼用這張表

- **找自己的板**：開場跑 `echo $HERMES_SESSION_ID`，用 id 拼路徑 `<白板根>\<id>.md`——同第 5 欄寫嘅係同一條路。
- **找任何一個板（主人用）**：直接 copy「完整路徑」欄，貼去檔案總管或 notepad，一次到位。
- **這張表給人看**：主人想知道「哪個對話在做什麼」，看這張。
- **加一行**：新 session 第一次開場建板時，順手加一行，**「完整路徑」欄唔准留空**。
- **移到歸檔**：主人明說「這個 session 不用了」才移。不主動刪（移了之後路徑欄要改成 `…\歸檔\<id>.md`）。
